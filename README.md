## Overview

FabFilter Pro-C 2 covers the full spectrum of compression styles—from clean, transparent glue to vintage pumping—in eight distinct modes with a highly visual interface.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **FabFilter Pro-C 2** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Eight Modes** | Clean, classic, opto, vintage, mastering, punch, vocal, and bus modes |
| **Large Display** | Visual gain reduction display with input/output overlay |
| **Sidechain** | External sidechain with filtering and listen option |
| **Auto Gain** | Automatic makeup gain maintains perceived loudness during adjustment |
